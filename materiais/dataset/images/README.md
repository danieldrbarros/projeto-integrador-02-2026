# Imagens

Esta pasta contém as imagens utilizadas pelo Projeto Integrador.

Os arquivos são referenciados pela coluna `image_file` presente em `chamados.csv`.

Exemplos:

- img_000001.jpg
- img_000002.jpg

As imagens podem representar:

- prints de tela;
- fotografias;
- documentos digitalizados;
- capturas de erros.

Os grupos poderão utilizar OpenCV, CNNs, Transfer Learning ou outras técnicas de Visão Computacional para extrair informações relevantes.
